# FINCODE · Лизинговые программы

Мини-кабинет вместо раздела **«Условия финансирования»**. Одна лизинговая программа, базовые ставки для всех партнёров и индивидуальные исключения без копии карточки.

## Что умеет

- Администратор и суперадминистратор управляют программами одинаково.
- Список программ показывает агрегаты: партнёры, базовые, индивидуальные.
- Назначение всем или выбранным партнёрам — без копирования программы.
- Индивидуальная ставка партнёра важнее базовой.
- Смена базовой ставки: к партнёрам с базовыми условиями / ко всем / только программа.
- Калькулятор и заявка в кабинете партнёра берут **применяемую** ставку. Партнёр ставку не меняет.
- Оформленная заявка хранит снимок условий и не пересчитывается.
- Неактивная программа недоступна для новых заявок.
- История изменений: кто, когда, срок, старое/новое значение, способ применения.
